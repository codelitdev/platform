The main action affordance; use `primary` once per view, `soft` for accent-tinted secondary emphasis.

```jsx
<Button variant="primary">Create course</Button>
<Button variant="outline" size="sm">Preview</Button>
```

Variants: primary (solid accent), secondary (warm gray), outline, ghost, soft (accent wash — CodeLit signature), destructive. Sizes sm/md/lg (30/36/42px). Labels are verb-first, sentence case.
