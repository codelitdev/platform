# Compatibility and support

Supported `@codelitdev/platform-preset` lines:

| Preset  | Status         | End of support           |
| ------- | -------------- | ------------------------ |
| `0.1.0` | current stable | supported for production |

`recommended` is the version emitted into a new product. `supported` is the
range covered by conformance. `minimumSecure` is monotonic within a major
line; `doctor` and conformance fail when a resolved package is older.

Prerelease tags are unsupported for production except by explicit origin-canary
agreement.
